# Analisis Kepuasan Penumpang Maskapai menggunakan Algoritma Machine Learning

## 1. Gambaran Umum Proyek

Proyek ini membahas tentang **analisis dan prediksi kepuasan penumpang maskapai menggunakan Logistic Regression**. Analisis dilakukan untuk mengidentifikasi faktor-faktor yang berkaitan dengan kepuasan penumpang terhadap layanan maskapai.


## 2. Tujuan

* Mengetahui proporsi penumpang yang puas dan tidak puas terhadap layanan maskapai.
* Membangun model *Logistic Regression* untuk mengklasifikasikan kepuasan penumpang.
* Mengidentifikasikan faktor yang berkaitan dengan kepuasan penumpang.
* Memberikan insight & rekomendasi untuk mendukung kualitas peningkatan layanan maskapai.


## 3. Dataset

Dataset yang digunakan dalam proyek ini adalah **Airline Satisfaction Data** yang bersumber dari website Kaggle. Dataset ini berisi lebih dari **129.000 baris** dan **22 kolom** yang mengandung informasi tentang penumpang, hingga penilaian layanan maskapai.


## 4. Proses Analisis

Analisis dalam proyek ini melalui beberapa tahapan berikut.

1. **Exploratory Data Analysis (EDA)** – Mengeksplorasi karakteristik data, distribusi dan proporsi variabel.
2. **Data Preprocessing** – Melakukan pengecekan data, encoding variabel kategorikal, dan standardisasi variabel numerik.
3. **Pemodelan *Logistic Regression*** – Membangun model untuk mengklasifikasikan tingkat kepuasan penumpang.
4. **Insight & Rekomendasi** – Mengidentifikasi faktor yang berkaitan dengan kepuasan penumpang serta memberikan rekomendasi untuk meningkatkan kualitas layanan maskapai.
